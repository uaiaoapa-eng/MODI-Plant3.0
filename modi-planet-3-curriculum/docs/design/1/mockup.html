교육용 바이브코딩 에이전트 (edu-agent)

만들고 싶은 것을 한국어로 말하면, AI 에이전트가 함께 설계하고 코드(웹·앱) 또는 MODI 하드웨어 블록까지 만들어 주는 교육용 도구입니다. 코드를 몰라도 자기 아이디어를 실제로 굴려볼 수 있게 돕습니다.

이게 뭔가요?

  • 학습자가 "배달 앱 만들고 싶어" 처럼 말하면, 에이전트가 되묻고 정리하며 설계도를 같이 그립니다.
  • 이야기가 충분히 되면 코드를 생성하고 결과를 미리보기로 보여줍니다.
  • 생성된 코드는 esbuild로 빌드되는지 자동 점검하고, 학습 노트·코드 설명도 붙여 줍니다.
  • 결과물 타입 2종: react 웹/앱 화면(JSX) · blockly MODI 하드웨어 블록(모터·LED·센서)

핵심 개념

모드 modedesign 설계부터 차근차근 / quick 설계 건너뛰고 바로 만들기
타입 coding_typereact 웹·앱 / blockly MODI 하드웨어
3단계 Phase설계(DESIGN) → 구현(IMPLEMENT) → 검증(VERIFY)
세션 session_id대화 단위. 메모리에 두고 projects/<id>.json으로 저장·복원

전체 아키텍처 구성도

```mermaid``` GitHub에서는 아래 코드블록이 다이어그램으로 렌더됩니다. (미리보기는 SVG로 그림)
진입 계층 에이전트 코어 외부 선택(관측)

에이전트 처리 프로세스 흐름도

/chat 요청이 들어온 뒤 StreamOrchestrator가 한 턴을 처리하는 흐름입니다.

```mermaid``` 요청 → 분류 → Phase 분기 → 에이전트 루프 → 검증 → 스트리밍 응답
분기 판단 에이전트 루프 응답/출력

디렉터리 / 모듈 설명

경로역할
server.py웹/API 진입점. FastAPI 앱. /chat(SSE), 세션 저장·복원·삭제, 프로젝트 목록.
main.py터미널 CLI 진입점. /diagram /phase /files /reset /quit.
agent/orchestrator_stream.py스트리밍 오케스트레이터. 한 턴 전체 흐름(라우팅→루프→검증·후처리).
agent/orchestrator.pyCLI용 얇은 래퍼. 내부적으로 StreamOrchestrator 사용.
agent/router.pyAPI 호출 없는 키워드 의도 분류기. 설계 단계엔 항상 설계 대화로.
agent/tools.py도구 11종 정의·실행 + MODI 코어 로딩 + Blockly XML 검증/자동수정. Phase별 허용 도구 상이.
agent/models.py도메인 모델 (pydantic): Phase, DesignDoc, TaskPlan, ProjectState 등.
agent/context.py세션 상태(SessionState). 대화·생성코드·학습노트·다이어그램 보관·요약.
agent/diagram.pymermaid 관리 + LLM 문법 자동 보정(_sanitize_mermaid).
agent/builder.py생성 React 코드를 esbuild로 번들 빌드 체크.
agent/modi_modules.pyMODI 하드웨어 모듈 배치·조립 가이드 생성(blockly).
agent/claude_client.pyLLM 호출 분기. 기본 로컬 Claude CLI, USE_LOCAL_CLAUDE=false면 API.
build_template/빌드 체크용 React 템플릿(React 18, react-router, lucide-react, esbuild).
docs/modi/MODI 코어(modi_core.md)·모듈 레퍼런스(ref/*.md). Blockly 검증 근거.

설치 / 실행

요구: Python 3.11+ · 의존성 anthropic · pydantic · fastapi · uvicorn · langfuse · python-dotenv

# 1) 설치
python -m venv .venv && source .venv/bin/activate
pip install -e .

# 2) .env (USE_LOCAL_CLAUDE=true 면 API 키 불필요)
#   ANTHROPIC_API_KEY=...   USE_LOCAL_CLAUDE=true

# 3a) 웹/API 서버
make run        # uvicorn server:app --host 0.0.0.0 --port 8000 --reload

# 3b) 터미널 CLI
python main.py

API 엔드포인트 요약

메서드경로설명
POST/chat메시지 → SSE 스트리밍 응답 (session_id, message, mode, coding_type)
POST/chat/stop진행 중 응답 중단
GET/session/{id}현재 phase·다이어그램 조회
POST/session/{id}/reset세션 초기화
POST/session/{id}/save · /restore세션 저장 / 복원
GET / DELETE/projects · /projects/{file}프로젝트 목록 / 불러오기 / 삭제

참고 / 주의

  • 기본은 로컬 Claude CLI(구독 인증). API 키로 바꾸려면 USE_LOCAL_CLAUDE=false + ANTHROPIC_API_KEY.
  • Langfuse는 선택 — 키 없으면 자동 비활성화.
