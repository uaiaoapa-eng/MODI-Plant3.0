# Lesson visual sources

The lesson-player visuals combine MODI product photography supplied by the user,
isolated MODI module renders extracted from the user's existing workshop decks,
and two original conceptual cutouts generated for this project.

## MODI module renders

- `modi-dial.png`, `modi-speaker.png`, `modi-led.png`, `modi-battery.png` —
  `MODI Workshop level 1 (3,4 grade).pptx`, `ppt/media/image67.png` through
  `image70.png`.
- `modi-network.png`, `modi-display.png` —
  `Pymodi 교육자료1/05Bool.pptx`, `ppt/media/image8.png` and `image9.png`.

The web copies are resized PNG derivatives. These images retain the supplied
MODI product appearance and are used only when the curriculum names the matching
module.

## Original conceptual cutouts

- `modi-hardware-kit.png` — original ImageGen illustration of an unlabeled,
  MODI-compatible educational module cluster.
- `web-modi-hybrid.png` — original ImageGen illustration of a web console,
  bidirectional data paths, modules, and a compact rover.

These two images are conceptual, intentionally contain no MODI logo or readable
product labels, and are not presented as photographs of a specific commercial
module.
