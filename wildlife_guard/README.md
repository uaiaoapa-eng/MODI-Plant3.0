# wildlife_guard — 강원도 논·밭 유해 야생동물 카메라 인식

논·밭 카메라(USB 웹캠 / CCTV RTSP / 녹화 영상)에서 농작물 피해 동물 **30종**을 인식해
알림·사진 기록·(선택) MODI 스피커/LED 퇴치를 수행합니다.

## 설치

```bash
pip install -r wildlife_guard/requirements.txt
```

## 실행

```bash
python -m wildlife_guard.guard --list                              # 30종 목록
python -m wildlife_guard.guard --source 0 --show                   # USB 웹캠, 화면 표시
python -m wildlife_guard.guard --source "rtsp://ID:PW@192.168.0.10/stream1" --camera-name 북쪽논
python -m wildlife_guard.guard --source 0 --webhook https://hooks.slack.com/...   # 메신저 알림
python -m wildlife_guard.guard --source 0 --modi                   # MODI 스피커·LED 퇴치 (pip install pymodi)
```

- 출현이 확정되면(최근 5회 추론 중 3회 이상 검출) 콘솔 출력 + `wildlife_events/snapshots/` 사진 + `events.csv` 기록
- 같은 동물은 `--cooldown`(기본 60초) 동안 재알림하지 않음
- 사람·차량·트랙터는 배경 클래스로 인식해 무시(농민을 곰·멧돼지로 오인 방지)
- CPU 기기(라즈베리파이 등)는 `--every 5 --imgsz 480` 처럼 부하를 낮추세요

## 인식 방식과 정확도 높이기

| 백엔드 | 장점 | 한계 |
|---|---|---|
| `world` (기본) | 학습 없이 바로 사용 (YOLO-World 제로샷, 영어 문구로 인식) | 고라니↔노루, 참새↔작은 새 같은 세부 종 구분이 약함 |
| `custom` | 현장 사진으로 학습 → 30종 정확 구분, 야간 IR 영상 대응 | 라벨링 데이터 필요 |

권장 순서: `world` 로 먼저 운영 → 쌓인 `snapshots/` 사진을 라벨링 → 학습 → `custom` 으로 교체.

```bash
python -m wildlife_guard.train --print-classes        # 클래스 번호 확인
python -m wildlife_guard.train --data-dir dataset --epochs 100
python -m wildlife_guard.guard --source 0 --backend custom --weights runs/detect/train/weights/best.pt
```

## 파일 구성

| 파일 | 역할 |
|---|---|
| `animals.py` | 30종 카탈로그(이름·위험도·피해·시기·인식 문구·보호종 여부) |
| `detector.py` | YOLO-World / 커스텀 YOLO 인식 |
| `events.py` | 연속 검출 확정 + 쿨다운 (오탐·알림 폭주 방지) |
| `alerts.py` | 알림 문구, 스냅샷·CSV 기록, 웹훅, MODI 퇴치 |
| `guard.py` | 카메라 실행기 (CLI) |
| `train.py` | 30종 커스텀 모델 학습 |
